   - Actor, tenant, and project scope
   - MCP/API server on Azure Container Apps
   - Zod tool contracts
   - Idempotency keys
   - Correlation IDs
   - Sanitized error handling
   - Confirmation before mutation

4. Core Domain Services
   - Capability Registry
   - Recommendation service
   - Proposal service
   - Deterministic risk scoring
   - Human review workflow
   - Approval / rejection service
   - Release packet generator
   - Capability map generator

5. Connectors, Providers, and Ingestion

   - Azure AI Foundry / Azure OpenAI
   - GitHub / GitHub Copilot assisted development
   - Synthetic enterprise data store
   - Target-state dashed: SharePoint, Teams, CRM, Service Desk, Finance system, HR system

6. Runtime Decisions and Workflow
   - User asks Copilot for role-relevant use cases
   - Agent reads approved work context
   - MCP recommends capabilities
   - User confirms proposal mutation
   - Proposal is written to registry
   - Risk score is deterministic source of truth
   - LLM advisory wording is non-authoritative
   - Human reviewer approves, rejects, or requests changes
   - Approved workflow is released with packet and audit trail
   - Unsafe employee monitoring request is blocked

7. Data, Evidence, and Durable State
   - Azure Table Storage registry mirror
   - Local JSON / SQLite synthetic registry
   - Capability records
   - Proposal records
   - Risk reviews
   - Review items
   - Release packets
   - MCP activity trail
   - Audit events
   - Key Vault for secrets/config
   - Application Insights + Log Analytics sanitized telemetry

8. Reporting, Operations, and Release Readiness
   - Static Web Apps hosted portal
   - Container Apps MCP/API runtime
   - Azure Container Registry image
   - Build/typecheck/test gates
   - Live health checks
   - Evidence package
   - Public GitHub repo for judging
   - YouTube/Vimeo demo video
