# Architecture Paragraph

Signal Foundry is a Microsoft 365 Copilot-first governance agent that turns employee AI ideas and approved work-context signals into reusable enterprise workflows. A Copilot declarative agent invokes an external MCP/API server on Azure Container Apps, where Zod-validated tools recommend capabilities, create proposals, apply deterministic risk gates, route human review, generate release packets, and write audit-safe registry events. The Foundry Floor portal, hosted on Azure Static Web Apps, visualizes the live registry through Copilot Mirror, Signal Atlas, Review Queue, Risk Gate, MCP Activity, and Executive views, while Azure Table Storage, Key Vault, Application Insights, and Log Analytics provide durable state, configuration, and sanitized evidence. Azure AI Foundry is used as an advisory reasoning layer only; the deterministic risk gate, human approval, tenant/project/actor scope, anti-surveillance refusal, and no-raw-content policy remain the authoritative controls.
