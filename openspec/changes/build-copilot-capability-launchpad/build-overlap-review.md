# Microsoft Build 2026 Overlap Review

## Summary

Signal Foundry should proceed if it is framed as a governed capability discovery and release workflow. It should not be framed as an always-on assistant, a general agent marketplace, or a generic Work IQ context demo.

## Relevant Build Announcements

- Microsoft Scout introduces an always-on personal agent that can operate across Teams, Outlook, OneDrive, SharePoint, chats, email, calendar, and contacts, and can spot risks like stalled decisions.
- Work IQ APIs are announced for general availability on June 16, 2026, with REST, A2A, and redesigned remote MCP support for Microsoft 365 context and actions.
- Microsoft Build 2026 positions Microsoft IQ as the context layer for agents and highlights Scout, Work IQ, Web IQ, Foundry, and governance.
- Microsoft 365 Copilot extensibility supports declarative agents with custom instructions, custom knowledge, and actions.

## Overlap Risks

### High Risk: Always-On Personal Agent

Do not build this as a Scout-like autonomous assistant. The hackathon product must be user-initiated in Copilot Chat and focused on capability release governance.

### Medium Risk: Agent Store / Agent 365

Do not claim to replace Agent Store or Agent 365. The product is not a distribution platform for every agent. It is a workflow for shaping, risk reviewing, and releasing organization-approved Copilot use cases.

### Medium Risk: Generic Work IQ Demo

Do not make the core value "we use Work IQ to recommend things." Work IQ is the grounding layer. The differentiator is the governed capability registry, risk gate, and release evidence.

### Low Risk: AI Adoption Coaching

AI adoption coaching is a strong business problem and not directly duplicated by the Build announcements if the product focuses on governed capability proposals and releases.

## Recommended Positioning

Use this pitch:

> Signal Foundry turns raw work signals into approved, reusable Copilot workflows through a governed risk gate, MCP-backed registry, and audit-safe release workflow.

Avoid this pitch:

> An always-on agent that monitors work and tells everyone what to do with AI.

## Go / No-Go

Go, with constraints:

- Copilot Chat remains the primary surface.
- Work IQ is used only as permission-aware context.
- MCP registry and writeback are central.
- Human review is mandatory for release.
- The product shows capabilities and workflows, not employee activity.
- The frontend shows audit-safe release evidence, not raw Microsoft 365 content.
