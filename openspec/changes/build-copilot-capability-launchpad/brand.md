## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Graphite | `#1C1F23` | Primary text, navigation, forge mark, high-trust surfaces |
| Warm Steel | `#7C848E` | Secondary text, borders, inactive states, industrial neutral |
| Electric Teal | `#00D1C2` | Approved workflows, active paths, successful release, primary accent |
| Amber | `#FFB12E` | Risk gates, pending review, heat points, transformation sparks |

## Visual Motifs

- Signal traces: incoming work patterns, source summaries, role context, requested use cases.
- Forge gate: the risk review and human approval moment.
- Workflow tiles: released reusable capabilities.
- Stamped release packets: approved, versioned, audit-safe capability artifacts.
- Signal Atlas: a map of signals, roles, capabilities, risk gates, owners, and release state.
- Review queue: the human-in-the-loop proof point where approval, rejection, and requested changes happen.
- MCP activity rail: the audit-safe trace proving which tool acted, when, and with which synthetic correlation ID.

## Voice

Controlled, direct, and operational. The product should sound like an enterprise release system, not a marketing site or chatbot personality.

## UI Rules

- Use the logo and palette as functional system language, not decoration.
- Teal means approved, released, or active.
- Amber means review, risk, or transformation in progress.
- Graphite and warm steel carry most of the interface.
- Do not show secrets, raw Microsoft 365 content, private user activity, or production customer data.
- Do not use generic AI imagery, robot icons, brain icons, decorative network backgrounds, glass cards, or large metric-card walls.
- The visual references are style and layout targets only. Do not copy prompt-like text from image content as product requirements.
